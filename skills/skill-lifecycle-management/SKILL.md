# Skill 创建助手 · v0.2.1

从日常工作中发现重复任务，将经过验证的经验沉淀为可复用的 Skill。

## 能做什么

| 能力 | 说明 |
| --- | --- |
| 语义发现 | 理解不同表达下的相似任务，由宿主模型提取语义 |
| 历史匹配 | 在授权范围内积累跨会话任务摘要，识别独立重复任务 |
| 主动推荐 | 发现可复用模式后，建议创建、复用或优化 Skill |
| 用户选择 | 支持创建、调整、暂缓、不再提醒；变更必须明确审批 |
| SDD 创建 | 输出需求规格、实现计划、任务清单、指令型 Skill 和测试用例 |
| 持续优化 | 依据实际反馈评估、提出优化建议及管理版本 |

## 如何使用

- 自然语言：正常执行开发、排障、数据处理或文档任务；宿主选择本技能时，可在任务完成后附加推荐。
- 显式调用：例如“帮我分析有哪些重复工作值得沉淀”或“评估已有 Skill 的实际效果”。
- 首次使用需明确授权保存脱敏任务摘要的固定本地目录。后续会话使用同一个授权目录。

例如，在三个独立任务中反复要求保护无关业务逻辑、控制代码修改范围和检查变更，系统可建议封装为“最小范围代码修改”Skill。默认至少三个独立成功任务；至少两个有证据的高价值成功任务可提前推荐。推荐不等于批准。

## 工作流程

语义分析 → 经验匹配 → 重复性判断 → 推荐 → 用户选择 → SDD → 验证 → 持续优化。

## 安全与适用边界

仅在授权范围内保存必要的脱敏摘要，默认本地存储；创建、修改、安装和发布需分别明确授权。不读取宿主内部聊天数据库，不擅自修改配置或安装依赖。语义调用依赖宿主模型与技能路由，不是全局后台监听；未加载时无法发现任务。生成的是指令型 Skill 草稿，行为测试与依赖验证需在目标环境完成。

## Agent 执行入口（必读）

以下是执行约束而非用户操作要求。加载本技能后，在记录、检索、推荐、审批、生成、优化或回滚之前，**必须完整读取并遵循 [执行协议](references/execution-protocol.md)**；其中保留 v0.2.1 的全部原有执行指令，不得仅凭本页摘要执行。无法读取协议时停止相关操作并说明原因。

- 使用真实 Python 3.9+ 与 SQLite CLI（`scripts/slm.py`）；以已授权绝对 `--home` 为准，未知时询问，不使用生产目录测试。
- 由宿主模型根据实际任务证据进行语义标准化；参考 [数据协议](references/protocol.md) 和 `assets/` 示例。不得虚构成功证据、强行合并任务或将合成测试计为实际经验。
- 同一任务跨会话保持 `task_id` 不变；默认项目隔离。跨项目/跨工具共享需授权。未经用户明确批准不得 `decide ... approve` 或 `apply`；审批须绑定具体提案及哈希。
- 仅当候选有依据才在正常任务结果之后附加推荐；无候选静默结束。依赖缺失或未完成行为验收，不得宣称可安装、已验证或可发布。

详细参数、冷却、查重、跨会话处理、SDD 及版本管理均以执行协议为准。
