# v0.2.0 产品规格（确认版）
目标：日常任务中主动发现重复能力，在当前任务结束时提出建议，用户选择后按 SDD 创建或优化。显式调用作为兜底。

- FR1：Skill 描述支持语义路由；宿主支持时自动选择，不能保证全量捕捉。普通闲聊不触发。
- FR2：固定授权用户目录，独立任务去重，默认同项目，已授权通用经验可跨项目。多窗口和多工具使用相同目录。隐私默认本地摘要。
- FR3：宿主 LLM 语义提取，核心保守匹配；默认3次，两条具证据高价值任务可提前推荐。通用工作任务，优先软件开发。
- FR4：推荐创建/复用/优化；支持调整、暂缓、忽略。24小时冷却+新证据；拒绝后不立即重推；忽略需显式恢复。推荐放在当前任务最终答复，不打断任务。
- FR5：提案哈希、用户明确审批、不可变版本、SDD 产物及真实行为验收，安装/发布另行授权。
- FR6：反馈枚举、冲突提示、版本查询、UTF-8、依赖声明及可发现性检查；无依赖自动安装。
- FR7：标准 Agent Skills 包和 TeleAgent 小写入口 ZIP 分开分发，保留 v0.1.0，旧数据库新增表向后兼容；升级前备份。
- 验收：原有15项回归、新增策略及跨进程测试；宿主真实自动选择、语义准确率、真实跨对话、依赖实际运行和发布另行验收。无模型级保证。

# v0.2.1 修复增量规格
- FR8 (D8)：项目+task_id 为独立任务身份；session_id 为可选溯源。同一已完成任务仅会话 ID 变化时必须幂等，保留原记录并关联新会话；其他内容冲突仍拒绝，不擅自覆盖成功证据。不同项目隔离；并发重试不增加计数。历史会话关系可查询。
- FR9 (D9)：新建及优化提案都必须明确提交完整 dependencies 列表（确认无额外依赖才使用 []）；保持依赖时必须原样列出当前版本列表，不能省略。缺失、非法或标记未确认时拒绝；审批及应用前校验提案哈希，应用时再次校验依赖声明，失败不切换版本。历史版本保留；未声明的历史草案仍可查询、导出供审查，但未完成提案须重新生成并审批。依赖可发现性与真实运行是独立验收；本地草稿注册/导出不是发布，缺失或未知禁止声称可安装/发布。
